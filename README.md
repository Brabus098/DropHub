# DropHub - Симулятор открытия кейсов

![Swift](https://img.shields.io/badge/Swift-5.9-FA7343?logo=swift)

**CS:GO Case Simulator** - интерактивное iOS-приложение для виртуального открытия кейсов CS:GO с гарантированным выпадением подарков. Создано для surprise-поздравлений друзей с элементами геймификации.

## 🎮 Возможности

### 🎁 Система открытия кейсов
- **Гарантированный дроп** - специальный алгоритм выпадения подарков
- **Анимированный процесс** открытия с пошаговой прокруткой предметов
- **Группы кейсов** по 10 предметов с одним гарантированным подарком
- **Прогрессивное открытие** всех кейсов для получения полного набора

### 📦 Управление инвентарем
- **Детальная информация** о каждом скине (описание, редкость)
- **Модальный просмотр** с возможностью детального рассмотрения
- **Категоризация предметов** по типам и редкости
- **История выпавших** предметов

### 🎉 Поздравительная система
- **Автоматические поздравления** после открытия всех кейсов
- **Направление в инвентарь** для просмотра полученных предметов
- **Интерактивные алерты** с персонализированными сообщениями

## ⚙️ Установка и запуск

### Требования
- macOS 14.0+
- Xcode 15.0+
- iOS 15.0+

### Быстрый старт

```bash
git clone https://github.com/Brabus098/Trains.git
cd Trains
open Trains.xcodeproj
```
1. Выберите симулятор или подключите устройство
2. Нажмите `Cmd + R` для сборки и запуска  
3. Начните открывать кейсы и собирать коллекцию скинов

## 🎯 Особенности реализации

### 🎲 Алгоритм выпадения предметов
- **Кастомная логика** гарантированного выпадения подарков
- **Пошаговая прокрутка** через 9 случайных предметов к целевому
- **Контроль последовательности** открытия всех кейсов
- **Визуальная драматургия** процесса открытия

### 🖼 Работа с контентом
- **Локальное хранение** изображений скинов в assets
- **Оптимизированная загрузка** графики без лагов
- **Адаптивные layout** для разных размеров экранов
- **Плавные анимации** переходов между экранами

### 🎪 Пользовательский опыт
- **Иммерсивный интерфейс** в стилистике CS:GO
- **Тактильная отдача** при взаимодействии
- **Интуитивная навигация** между разделами
- **Мотивационные элементы** геймификации
