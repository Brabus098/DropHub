
# ``DropHub/GameManager``

- Менеджер для запуска игры(таймера). 
- Содержит метод который принимает итоговый список скинов которые должны выпасть

## Overview

Принимает на вход массив WeaponsForPresent. 
Запускает таймер, на каждый тик таймера обновляет UI новой картинкой. Достигая конца массива переходит к следующему, в противном случае показывает поздравительный алерт.

## Методы

- ``startGame()`` 
- ``updateWeaponAnimationFrames(_:)``
