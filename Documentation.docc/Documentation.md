# ``DropHub``

Приложение для розыгрыша скинов с гарантированным выигрышем для друзей.

## Overview

DropHub - это приложение, которое позволяет создавать честные розыгрыши игровых скинов между друзьями. В отличие от обычных кейсов, здесь каждый участник гарантированно получает выигрыш.

### Основные возможности

- 🎁 **Честные розыгрыши** - алгоритм гарантирует, что каждый участник получит приз
- 📱 **Инвентарь** - все полученные предметы сохраняются в личном кабинете
- 🎮 **Интерактивная анимация** - реалистичная анимация открытия кейсов

### Архитектура

Приложение построено на архитектуре **MVVM** с использованием:
- `GameManager` - управление логикой розыгрыша
- `GameFabric` - создание и подготовка данных
- `GameLogic` - содержит игровую логику
- `InventoryFabric` - создание и подготовка данных
- `InventoryViewController` - отображение полученных предметов
